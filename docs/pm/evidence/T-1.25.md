## Defect

The reader `app/snapshot.py:55` (`LiveSnapshotStore(full_check=False)`) calls
`ingest/snapshots.py:305` `open_current(full_check=False)`. That skips the manifest checksums
(`ingest/snapshots.py:230-234`) and only runs `select count(*) from marts.games`
(`:238`), which DuckDB answers from metadata. A snapshot with a corrupted data block or tampered
shot files is served. Queries then fail with `IO Error: Corrupt database file`.
