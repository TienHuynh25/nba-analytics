## T-DET (DEF-021): deterministic marts, final rebuild

Audit (T-DET-1-before.log): 4 dbt builds from data/build/landing.duckdb into scratch files
(threads 1 / 4 / default, preserve_insertion_order false/true). Content differed in
marts.player_season (last_team_id), marts.player_aliases (kind) and the semantic views over them.
Row order differed in 20 tables (12 marts, 8 staging), and all 30 shot Parquet files differed
byte for byte. After the fixes (T-DET-1-after.log), 4 builds give 0 differences: row counts,
content, row order and Parquet bytes all match, 145/145 nodes pass in each.

Fixes:
- player_season.last_team (comment in the model): latest game date, then a team the source lists as
  a stint, then the later-joined stint (later first game), then the higher game_id (a total
  order). Only 5 player-seasons tie on date. Values (T-DET-3-lastteam.log), each matching the source's
  chronological stint order:
  76418 1980-81 WAS, 76444 1982-83 LAL (one stint; a same-day LAC game is a source error),
  77136 1982-83 PHL, 77167 1981-82 DET, 78538 1984-85 LAC. Against rework 1 (T-DET-11-vs-r1.log),
  3 changed: 76418 ATL->WAS, 76444 LAC->LAL, 77167 SEA->DET. No other column or row changed.
- player_aliases: curated tie-break `p.player_id`; final pick `kind='full name' desc, alias,
  is_curated desc, kind` (Durant: curated 'best-known holder', same as rework 1).
  team_aliases: arg_max(abbreviation, game_id) instead of any_value; `alias` tie-break.
- Every mart and staging model ends with `order by all`; shots are ordered by
  (season, game_id, game_event_id), which is unique.
- Float sums: no mart or semantic view varied (4 builds, and 10 repeat reads of all 19 views,
  T-DET-10). The float variation is in query-time AVG in seed SQL only (Q62, Q72).

Tools (app/tools/stats.py): tie-breaks added at the end of ORDER BY, so the top rows do not change
when there is no tie. zones +zone; team leaders +team_id; player leaders: candidates ordered by player_id
before the stable sort; standings +win_pct desc, wins desc, team_id; game log +game_id desc;
player points +game_id, player_id; games +game_id; box leaders +player_id; streak +game_id;
