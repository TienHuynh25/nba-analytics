# True shooting percentage (TS%)

True shooting percentage measures scoring efficiency. It counts 2-pointers, 3-pointers and free
throws together, which plain field goal percentage does not.

**Formula:** TS% = PTS / (2 × (FGA + 0.44 × FTA))

- PTS is points scored, FGA is field goal attempts and FTA is free throw attempts.
- The 0.44 factor estimates how many possessions free throw attempts use. Some trips are two shots,
  some are three, and-ones add a single shot, and technical free throws use no possession.
- Multiplying the attempts by 2 puts the result on the same scale as field goal percentage.

**Caveats:** TS% says nothing about shot difficulty or volume. Leader lists use the per-game
leader games minimum, since NBA.com lists no separate TS% minimum.
